## Logique STOMP commune

| FS | Fonction generale | Exceptions utiles |
|----|-------------------|-------------------|
| FS1 | GAIN : changement de Drive et Ch Vol de l'ampli | 06D ajoute HBE |
| FS2 | Couleur forte | D9 sur 06C, Scream sur 06D, octave sur 07B |
| FS3 | SOLO : delay + changement du Preset EQ | 06D ajoute un compresseur leger |
| FS4 | SPACE : reverb | Plate ou Glitz selon le preset |
| FS5 | Utilitaire | Comp, boost, chorus ou serrage de l'ampli |
| FS6 | Cab/IR pour le casque | Toujours OFF vers le vrai baffle |

`ON/OFF` indique l'etat du footswitch. `Au choix` signifie que la section fonctionne dans les deux etats selon l'espace disponible dans le mix.

## Egalisation des niveaux

Reglage commun : `Global Settings > Ins/Outs > Main Out Level = Line`. Dans chaque preset, le bloc Output reste `Pan Center`, `Level 0.0 dB`.

| Preset | Etat de reference | Ch Vol initial |
|--------|-------------------|----------------|
| 06A | FS1 OFF, base | 9.5 |
| 06B | FS1 OFF, base | 7.6 |
| 06C | FS1/FS2 OFF | 7.8 |
| 06D | FS1 OFF, FS2 ON | 7.4 |
| 07A | FS1 OFF, base | 8.7 |
| 07B | FS1 OFF, base | 8.0 |

1. Utiliser le meme riff, le meme micro, Volume a 100%, FS3 OFF et IR bypass.
2. Prendre 06A comme reference et comparer au volume de repetition, pas a faible volume.
3. Ajuster uniquement `Ch Vol` par pas de 0.2 jusqu'a un ecart percu inferieur a environ 1 dB.
4. Verifier ensuite chaque `FS1 GAIN`. Sa valeur de `Ch Vol` plus basse doit eviter un saut de volume excessif.
5. Regler enfin `FS3 SOLO` pour environ +1.5 a +2 dB percus dans le groupe.

Les valeurs proposees sont coherentes comme points de depart, mais aucun document ne peut garantir six niveaux acoustiques identiques sans mesure sur le Katana, le baffle et au volume reel.
